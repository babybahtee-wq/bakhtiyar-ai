# BAKHTIYAR AI — prototype v1

Мобильный веб-прототип с тёмным Premium-интерфейсом и настоящим ИИ-чатом через OpenAI Responses API.

## Запуск в Replit с iPhone

1. Скачай ZIP и открой Replit в Safari: https://replit.com/
2. Создай новый Node.js проект (или импортируй ZIP, если в твоём интерфейсе доступен Import).
3. Загрузи файлы проекта, сохрани структуру папок.
4. В Replit открой **Secrets** (иконка замка) и добавь:
   - Key: `OPENAI_API_KEY`
   - Value: твой API key из https://platform.openai.com/api-keys
5. В Shell выполни `npm install`, затем `npm start`.
6. Нажми Run. Открой опубликованный preview URL.

## Важно

- Нужен отдельный OpenAI API key и доступ к API. Подписка ChatGPT сама по себе не включает API-кредиты; API тарифицируется отдельно.
- Никогда не вставляй API key в `public/index.html`, не отправляй его в чат и не публикуй в репозитории.
- API key хранится в Secrets/переменных окружения на серверной стороне.
- Модель по умолчанию задаётся через `OPENAI_MODEL`; если выбранная модель недоступна для твоего API-проекта, укажи доступную модель.
- Сейчас это прототип: нет регистрации, базы данных, долговременной истории, голосового режима и платёжной системы. Чат хранится только в памяти страницы браузера.
- Перед публичным запуском добавь авторизацию, ограничения запросов, лимиты расходов и политику конфиденциальности.

## Технологии

Node.js, Express, OpenAI JavaScript SDK, Responses API, адаптивный HTML/CSS/JS.
